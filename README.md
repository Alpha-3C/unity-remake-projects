# Unity 复刻实战记录

## 总目标

通过循序渐进地复刻不同类型的小游戏，掌握 Unity 与 C# 的核心开发流程：玩法实现、场景与资源管理、交互和界面、调试、构建，以及项目复盘。每个项目以一个可玩、可展示的最小版本为目标，再逐步迭代。

项目类型与开源参考见 [Unity 复刻实战总纲](Unity复刻实战总纲.md)。学习日志由我按实际进度持续更新。

## 已完成项目

- [1. 2048 复刻实战](1.2048)：4×4 数字合并游戏，包含 Unity 源码、项目说明与学习记录。

`1.2048` 是独立仓库 [unity-2048](https://github.com/Alpha-3C/unity-2048) 的 Git 子模块。克隆本仓库时使用 `git clone --recurse-submodules`，即可一并获取项目文件。
